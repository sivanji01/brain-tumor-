##  About the Project

Brain tumour detection is an important application of medical imaging and computational techniques in healthcare.

This project explores the development of a web-based brain tumour detection application, combining biomedical engineering concepts with modern frontend technologies.

The goal is to build an accessible and intuitive interface for presenting medical imaging-related functionality.

##  Technology Stack

##  Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/sivanji01/medical-image-processing.git
```

**2. Navigate to the project directory**

```bash
cd medical-image-processing
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 📦 Available Commands

| Command | Description |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
